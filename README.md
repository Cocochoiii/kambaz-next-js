# Kambaz - Next.js (A3)

Coco Choi. CS5610 Web Development, Fall 2025, Section 04.

This is my A3 work. It is Chapter 3 of the book, *Developing Full Stack MERN
Web Applications*.

Lab 3 practices JavaScript and React. The Kambaz screens are data driven now:
they read their content from the JSON files in `app/(Kambaz)/Database`, so
every course shows its own modules, assignments, and people.

## How to run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000. The first screen is Kambaz. The menu on the
left has a Labs link, and `/Labs` lists Lab 1, Lab 2, and Lab 3.

## Folders

- `app/(Kambaz)` - the Kambaz screens: Account, Dashboard, Courses, and more
- `app/(Kambaz)/Database` - the data as JSON: courses, modules, assignments,
  users, enrollments, announcements, and quizzes
- `app/Labs` - the lab exercises for chapters 1, 2, and 3
