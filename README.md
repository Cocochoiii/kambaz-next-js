# kambaz-next-js - A2 (CSS and Bootstrap)

CS5610 Web Development, Fall 2025, Section 04 - Coco Choi

This is Chapter 2 of the book. In A1 the screens were plain HTML.
In A2 I styled the same screens with CSS and Bootstrap.

## What is new in this branch

- Lab 2 has all the CSS exercises: selectors, colors, borders, padding,
  margins, corners, dimensions, position, z-index, float, grid, and flex.
- Lab 2 also has the Bootstrap exercises: container, grids, responsive
  columns, screen size label, tables, lists, forms, tabs, pills, and cards.
- The Labs table of contents is now Bootstrap pills.
- Kambaz is styled with Bootstrap: the navigation sidebar, the Dashboard
  cards, the Course navigation sidebar, Modules, Home, People,
  Assignments, the Assignment Editor, and the Account screens.

## Run it

    npm install
    npm run dev

Open http://localhost:3000
